# Internal scan evidence (public, non-alerting)

This branch stores the most recent free GitHub Actions browser scan evidence in `evidence/latest.json` and a human-readable status in `evidence/latest.md`.

It is **not** an inventory feed or proof of orderability. A URL, price or browser success here does not imply a qualifying purchasable PS5. Checkout verification must pass separately before an alert.

Only public product metadata and generic Phoenix ZIP 85001 are stored. No cookies, user addresses, retailer logins, or payment data should be committed here.
